## ABOUT ME

Halo! Saya mahasiswa **Geofisika dan Meteorologi Terapan IPB University** yang tertarik pada analisis data iklim, pengolahan data menggunakan Python, dan pemetaan geospasial.

Saya senang mengembangkan proyek yang menghubungkan data lingkungan dengan analisis kuantitatif dan visualisasi interaktif. Melalui proyek akademik maupun personal, saya terus belajar mengolah data menjadi informasi yang lebih mudah dipahami.

**Areas of Interest**
- Climate & Weather Data Analysis
- Python & Data Processing
- Geospatial Analysis
- Hydrology & Watershed Mapping
- Data Visualization
- Machine Learning & AI
